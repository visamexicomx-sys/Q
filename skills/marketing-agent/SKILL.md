# Marketing Agent

A specialized agent skill for creating high-quality marketing content across all channels and formats.

## When to Use This Skill

Use this skill when the user asks to:

- Write landing page copy or hero sections
- Create email campaigns or newsletters
- Draft social media posts (Twitter/X, LinkedIn, Instagram)
- Write ad copy (Google Ads, Meta, LinkedIn Ads)
- Create product descriptions or feature announcements
- Draft blog posts or thought leadership articles
- Write press releases or product launch announcements
- Develop brand voice and messaging frameworks
- Create onboarding sequences or drip campaigns
- Write SEO-optimized content

## Workflow

### Step 1: Gather Context

Before writing, collect the following:

1. **Product/Service** — What is being marketed?
2. **Target Audience** — Who are you speaking to? (role, industry, pain points)
3. **Goal** — Awareness, conversion, retention, or engagement?
4. **Tone** — Professional, playful, bold, empathetic?
5. **Channel** — Where will this content appear?
6. **CTA** — What action should the reader take?

If any of these are missing, ask the user before writing.

### Step 2: Write with Frameworks

Apply proven copywriting frameworks based on the content type:

| Content Type       | Framework                        |
| ------------------ | -------------------------------- |
| Landing page hero  | Problem → Solution → Proof → CTA |
| Ad copy            | Hook → Benefit → CTA             |
| Email subject line | Curiosity / Urgency / Benefit    |
| Social post        | Hook → Value → Engagement prompt |
| Product description| Feature → Benefit → Outcome      |
| Blog post          | SEO headline → Intro → H2s → CTA |

### Step 3: Deliver Multiple Variants

Always provide **2–3 variants** so the user can A/B test or choose. Label them clearly:

```
Variant A — Direct / Benefit-led
Variant B — Emotional / Story-led
Variant C — Bold / Provocative
```

### Step 4: Add Usage Notes

After each piece of content, include a brief note:
- Where it works best
- What to test first
- Any platform-specific character limits

## Content Templates

### Landing Page Hero

```
Headline: [Outcome the user wants]
Subheadline: [How your product delivers it, for whom]
CTA Button: [Action verb] + [Specific outcome]

Social Proof: [Number] [users/teams/companies] already [result]
```

### Cold Email

```
Subject: [Specific result] for [their company/role]

Hi [Name],

[1 sentence on why you're reaching out — reference something specific]

[1–2 sentences on the problem you solve]

[1 sentence proof — customer name, metric, or outcome]

Worth a 15-min call this week?

[Signature]
```

### Social Post (LinkedIn)

```
[Bold hook — a counterintuitive claim or stat]

[2–3 lines expanding on the idea]

[Practical insight or takeaway]

[Engagement question or CTA]

#[Hashtag1] #[Hashtag2]
```

### Product Announcement

```
🚀 Introducing [Feature Name]

[One-line description of what it does]

Why it matters:
→ [Benefit 1]
→ [Benefit 2]
→ [Benefit 3]

[Link or CTA]
```

## Tone Guidelines

| Tone        | Use When                              | Avoid                          |
| ----------- | ------------------------------------- | ------------------------------ |
| Professional| B2B, enterprise, finance, legal       | Jargon, passive voice          |
| Playful     | Consumer apps, early-stage startups   | Forced humor, slang overuse    |
| Bold        | Competitive markets, challenger brands| Arrogance, unverified claims   |
| Empathetic  | Healthcare, education, nonprofits     | Clichés, hollow reassurances   |

## SEO Content Guidelines

When writing blog posts or web pages:

1. **Target one primary keyword** per page
2. **Include keyword** in title, first 100 words, one H2, and meta description
3. **Meta description**: 150–160 characters, include CTA
4. **Title tag**: 50–60 characters, keyword near the front
5. **Internal links**: suggest 2–3 relevant internal link opportunities
6. **Word count**: 1,200–2,000 words for competitive topics

## Platform Character Limits

| Platform          | Limit                              |
| ----------------- | ---------------------------------- |
| Google Ads headline| 30 characters                    |
| Google Ads description| 90 characters               |
| Meta ad primary text| 125 characters (before truncation)|
| Twitter/X post    | 280 characters                     |
| LinkedIn post     | 3,000 characters (600 ideal)       |
| Email subject line| 40–50 characters                   |
| Meta description  | 150–160 characters                 |

## Quality Checklist

Before delivering any content, verify:

- [ ] Speaks directly to the target audience's pain or desire
- [ ] Lead with benefit, not feature
- [ ] One clear CTA per piece
- [ ] No filler phrases ("In today's world...", "We're excited to...")
- [ ] Active voice throughout
- [ ] Passes the "so what?" test on every sentence
- [ ] Fits within platform character limits
- [ ] Includes a hook in the first line
