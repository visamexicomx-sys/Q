# Content Scripter

A specialized skill for writing compelling, platform-optimized scripts for video and audio content.

## When to Use This Skill

Use this skill when the user asks to:

- Write a script for an Instagram Reel or TikTok video
- Create a YouTube video script (short or long form)
- Script a podcast episode or segment
- Write a talking-head or explainer video script
- Create a product demo or walkthrough script
- Draft a webinar or live stream outline
- Write a video ad script (15s, 30s, 60s)

## Workflow

### Step 1: Gather Context

Before scripting, collect:

1. **Platform** — TikTok, Instagram Reels, YouTube, Podcast, Webinar, Ad?
2. **Video length** — Target duration (e.g., 30s, 60s, 5 min, 10 min)
3. **Topic** — What is the video about?
4. **Goal** — Educate, entertain, convert, build authority, or drive action?
5. **Audience** — Who is watching/listening?
6. **Tone** — Casual, professional, energetic, calm, humorous?
7. **Hook style** — Question, bold claim, story, stat, or challenge?
8. **CTA** — What should viewers do after watching?

### Step 2: Apply Script Structure by Format

#### Short-Form Video (Reels / TikTok — 15s to 90s)

```
[0–3s]  HOOK      — Grab attention immediately
[3–15s] SETUP     — Frame the problem or promise
[15–Xs] VALUE     — Deliver the core insight, tip, or story beat
[Last 5s] CTA     — Single, direct ask
```

#### Long-Form YouTube (5–15 min)

```
[0–30s]   HOOK        — Bold statement, question, or teaser of the payoff
[30–90s]  INTRO       — Who you are (briefly), what this video covers, why it matters
[90s–end] BODY        — 3–5 main points, each with: claim → explanation → example
[Last 60s] OUTRO      — Recap key takeaway + CTA (subscribe, watch next, download)
```

#### Podcast Episode

```
COLD OPEN  — Teaser clip or provocative question (30–60s)
INTRO      — Host intro, episode topic, guest intro if applicable
ACT 1      — Context and background
ACT 2      — Core conversation or main content
ACT 3      — Takeaways, lessons, or recommendations
OUTRO      — Summary, CTA, next episode tease
```

#### Video Ad (15s / 30s / 60s)

```
[0–3s]   HOOK      — Pattern interrupt: unexpected visual, sound, or claim
[3–10s]  PROBLEM   — Identify the pain the viewer has
[10–25s] SOLUTION  — Introduce product/service as the answer
[25–28s] PROOF     — One line of social proof or result
[28–30s] CTA       — Click, shop, sign up, learn more
```

### Step 3: Write the Script

Deliver the script in this format:

```
--- [SECTION NAME] ---
[TIMESTAMP or DURATION]

[ON SCREEN / VISUAL NOTE]: What the viewer sees
[SPOKEN]: Exact words to say
[DIRECTION]: Tone, pace, or delivery note (optional)
```

#### Script Writing Rules

- **First 3 seconds are everything** — lead with the most compelling hook, never the intro
- **Write for speaking, not reading** — use contractions, short sentences, natural rhythm
- **One idea per sentence** — never combine two thoughts in one sentence
- **Specificity > generality** — "42% of marketers" beats "many marketers"
- **Active voice only** — "You'll save 2 hours" not "2 hours can be saved"
- **Read it aloud** — if it doesn't flow naturally when spoken, rewrite it

### Step 4: Add Production Notes

After the script, include:

```
## Production Notes
- **B-roll suggestions**: [what footage or visuals would support each section]
- **On-screen text**: [key phrases to display as text overlays]
- **Music mood**: [energy level and style of background music]
- **Pacing**: [fast cut, slow build, etc.]
- **Estimated runtime**: [word count ÷ 130 words/min = minutes]
```

## Script Templates

### 60-Second Reel / TikTok (Educational)

```
[0–3s] HOOK
SPOKEN: "Most people [do X wrong / don't know Y / think Z is true]."
VISUAL: Talking head, direct eye contact, energetic

[3–10s] SETUP
SPOKEN: "Here's what's actually happening — [1 sentence problem statement]."

[10–50s] VALUE (3 tips, ~13s each)
SPOKEN: "Number one: [tip]. [1 sentence why it works]."
SPOKEN: "Number two: [tip]. [1 sentence why it works]."
SPOKEN: "Number three: [tip]. [1 sentence why it works]."

[50–60s] CTA
SPOKEN: "Save this video so you don't forget. Follow for more [topic] every week."
```

### 90-Second Product Reel

```
[0–3s] HOOK
SPOKEN: "I stopped [old painful thing] the moment I found this."

[3–15s] PROBLEM
SPOKEN: "[Describe the frustration authentically — 2–3 sentences]"

[15–60s] DEMO
SPOKEN: "[Walk through the product doing the thing — show, don't just tell]"

[60–80s] RESULT
SPOKEN: "[Specific outcome: time saved, money earned, stress removed]"

[80–90s] CTA
SPOKEN: "Link in bio — [offer or urgency]."
```

### YouTube Intro (30s)

```
HOOK (0–5s):
SPOKEN: "[Bold claim or surprising statement about the topic]"

PROMISE (5–15s):
SPOKEN: "In this video, I'm going to show you [specific outcome] — 
         even if [common objection or barrier]."

CREDIBILITY (15–25s):
SPOKEN: "[One sentence on why you're the right person to teach this]"

SUBSCRIBE BUMP (25–30s):
SPOKEN: "If you're new here, subscribe — I post [topic] every [cadence]."
```

## Word Count to Runtime Guide

| Duration | Target Word Count |
|----------|-------------------|
| 15s      | ~30 words         |
| 30s      | ~65 words         |
| 60s      | ~130 words        |
| 90s      | ~195 words        |
| 3 min    | ~390 words        |
| 5 min    | ~650 words        |
| 10 min   | ~1,300 words      |

## Quality Checklist

Before delivering any script, verify:

- [ ] First 3 seconds contain a genuine hook — not an intro or greeting
- [ ] Script reads naturally when spoken aloud
- [ ] No sentence is longer than 20 words
- [ ] One clear CTA at the end — not multiple asks
- [ ] Production notes included for every major section
- [ ] Word count matches the target runtime
- [ ] Tone matches the platform and audience
- [ ] Specific examples or data used, not vague generalities
