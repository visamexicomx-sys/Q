## Launch Sequence (Prioritized)

### Week 1 — Foundation
- [ ] Set up Google Analytics 4 + Google Tag Manager
- [ ] Install Meta Pixel on website
- [ ] Optimize Google Business Profile (complete all fields, add 20 photos)
- [ ] Set up WhatsApp Business with greeting/away messages and quick replies
- [ ] Fix website speed issues (target 75+ PageSpeed score)

### Week 2 — Paid Ads Go Live
- [ ] Launch Google Search Campaign — English ($15/day)
- [ ] Launch Meta Lead Gen Campaign — Expats ($15/day)
- [ ] Set up conversion tracking (WhatsApp clicks + form submissions)
- [ ] Create Mailchimp/ActiveCampaign account and import email sequence

### Week 3 — Organic
- [ ] Post first TikTok video (project time-lapse or tour)
- [ ] Post in 5 expat Facebook groups (value post, no pitch)
- [ ] Publish first SEO blog post
- [ ] Send referral pitch to 10 real estate agents

### Week 4 — Scale
- [ ] Review ad performance → adjust budgets
- [ ] Reach out to 10 more realtors
- [ ] Post TikTok 5x this week
- [ ] Start Google Search Campaign — Spanish ($10/day)

### Month 2–3 — Compound Growth
- [ ] Retargeting campaigns live (Meta + Google Display)
- [ ] 2 SEO blog posts live
- [ ] 5+ agent referral partnerships signed
- [ ] 500+ TikTok followers
